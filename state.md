**Грабли, на которые уже наступали** (не повторять):
- **`.min(1)` на имени строки, которую UI создаёт пустой, = потеря персонажа.** Чтение из localStorage отбрасывает персонажа целиком, если хоть одна вложенная строка не прошла валидацию. Пустая строка — законное промежуточное состояние листа с инлайн-редактированием.
- Поля форм связывать **явными `htmlFor`/`id`**, не вложением `<label><select>…</label>` — иначе доступное имя поля склеивается с текстом выбранной опции и меняется при выборе.
- Любое изменение UI **проверять в реальном браузере**, а не только jsdom-тестами: так были найдены переполнение таблицы при печати и на экране, поломанная a11y, протечка тёмной темы, нерабочее определение локали.
- После правок вёрстки **перепроверять печать** — она завязана на семантику разметки.
- **`<textarea>` на печати не прокручивается** — то, что не влезло в высоту поля, на бумагу не попадёт. Поля с текстом должны расти под содержимое (плюс рамки к `scrollHeight` при `box-sizing: border-box`).
- **Картинки от пользователя ужимать перед localStorage** — квота на весь origin несколько мегабайт, одна фотография выносит весь ростер.
- **`transition` на цвете ломает печать:** правило печати может матчиться верно, а на бумагу попасть экранный цвет, если свойство анимировано (поймано на полосках HP/MP). В `@media print` анимации гасить.
- Проверяя печать через Playwright, **давать странице осесть после `emulateMedia({ media: 'print' })`** — иначе замеряется середина перехода, а не итоговый вид.
- **Скрипт для Playwright класть в корень репозитория, а не во внешнюю временную папку** — Node ищет `node_modules` вверх от файла скрипта, из чужой директории `import 'playwright'` не резолвится. Временный файл потом удалять.
- Пара «заголовок + пустой блок» на печати убирается обёрткой `.subsection` (`display: contents` на экране) с атрибутом `data-print-empty` — считать пустоту в React, а не угадывать её селекторами.

## Что известно о листе (итоги разбора)

24 класса, 18 рас (Core I–III + Outlaw + Abyssborn/Newman), 12+ магических школ, Adventurer Level cap = 15. Ключевые формулы подтверждены:

- `HP = Adv.Level × 3 + VIT`
- `MP = Σ Wizard Class Levels × 3 + SPR`
- `Modifier = floor(stat / 6)`
- `DEX = Skill + A`, `AGI = Skill + B`, `STR = Body + C`, `VIT = Body + D`, `INT = Mind + E`, `SPR = Mind + F`
- `Bardic Power = Bard Level + INT modifier` (для Finales)
- `Enhancer SV = Enhancer Level + INT modifier` (для Fire Breath)

Полная структура: `docs/sheet-content/00-index.md`
