# Features

## Решено

| Вопрос | Решение |
|--------|---------|
| Аккаунты / облако | Нет |
| Хранение | localStorage (автосохранение) + ручной экспорт/импорт JSON |
| Локализация | en + ru, с возможностью добавить другие языки |
| Печатный вид | Да, отдельный print-layout |

## MVP (минимально рабочий продукт)

- [ ] Лист персонажа — все секции (см. [sheet-content.md](sheet-content.md))
- [ ] Автоматический расчёт производных значений (HP, MP, бонусы к броскам)
- [ ] Автосохранение в localStorage
- [ ] Экспорт персонажа в JSON
- [ ] Импорт персонажа из JSON (с валидацией)
- [ ] Переключатель языка EN / RU
- [ ] Печатный вид (CSS print или PDF)
- [ ] Список персонажей (несколько в одном браузере)

## Открытые вопросы

### Калькуляция

- Насколько "умным" делаем лист?
  - **Вариант А — умный**: вводишь характеристики и классы, всё считается само (HP, MP, бонусы к броскам, инициатива)
  - **Вариант Б — ручной**: все поля свободно редактируются, калькуляция опциональная / только подсказки
  - Вариант А удобнее, но требует точного знания формул SW 2.5

### Dice roller

- Встроенный? Клик по бонусу → бросок 2d6 + бонус, лог результатов?
- Или это out-of-scope для MVP?

### Список персонажей

- Несколько персонажей в localStorage (нужен менеджер персонажей)?
- Или один активный + ручной экспорт/импорт для переключения?

### Версионирование JSON-схемы

- Поле `schemaVersion` в JSON с первой версии?
- При импорте старой версии — silent migration или предупреждение?

### Печать

- Только браузерный Ctrl+P (CSS @media print)?
- Или кнопка "Скачать PDF" (react-to-print / @react-pdf/renderer)?

### Статус-эффекты и трекеры

- Трекер HP/MP во время сессии (current vs max)?
- Трекер статус-эффектов (яд, паралич, etc.) — нужен в MVP?
