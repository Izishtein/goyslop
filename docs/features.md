# Features

## Решено

| Вопрос | Решение |
|--------|---------|
| Аккаунты / облако | Нет |
| Хранение | localStorage (автосохранение) + ручной экспорт/импорт JSON |
| Локализация | en + ru, с возможностью добавить другие языки |
| Печатный вид | Да, кнопка "Скачать PDF" (react-to-print / @react-pdf/renderer), не только CSS print |
| Калькуляция | Умная (Вариант А) — HP, MP, бонусы к броскам, инициатива считаются автоматически по формулам SW 2.5 |
| Dice roller | Вне MVP — отдельная фича после MVP |
| Список персонажей | Несколько персонажей в localStorage, нужен менеджер персонажей (список, создать/удалить/переключиться) |
| Версионирование JSON | Поле `schemaVersion` с первой версии |

## MVP (минимально рабочий продукт)

- [ ] Лист персонажа — все секции (см. [sheet-content.md](sheet-content.md))
- [ ] Автоматический расчёт производных значений (HP, MP, бонусы к броскам)
- [ ] Автосохранение в localStorage
- [ ] Экспорт персонажа в JSON
- [ ] Импорт персонажа из JSON (с валидацией)
- [ ] Переключатель языка EN / RU
- [ ] Печатный вид (CSS print или PDF)
- [ ] Список персонажей (несколько в одном браузере)
