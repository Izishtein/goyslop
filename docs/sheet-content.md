## 1. Базовая информация персонажа

- Имя персонажа
- Пол, возраст
- Раса (и расовые способности)
- Предыстория / история
- Аватар / портрет
- Уровень авантюриста (Adventurer Level) — максимальный среди всех классов
- Ранг гильдии авантюристов + оценка ранга

---

## 2. Шесть базовых характеристик (能力値)

| Аббревиатура | Название | Применение |
|---|---|---|
| STR | Strength / 筋力 | Физическая сила, бонус урона |
| AGI | Agility / 敏捷 | Уклонение, рефлексы |
| DEX | Dexterity / 器用 | Точность атаки (все типы оружия) |
| VIT | Vitality / 生命力 | HP, стойкость к яду/болезни |
| INT | Intelligence / 知力 | Волшебные классы, знание заклинаний |
| SPR | Spirit / 精神 | Магосопротивление, MP |

**Структура поля характеристики:**
- Base (базовое)
- Correction A/B/C/D/E/F (коррекции от расы, возраста, роста)
- Growth (прирост от развития)
- Итог

**Формула бонуса:** `Значение ÷ 6` (округление вниз)
- 6–7 → +1, 8–9 → +1, 10–11 → +1, 12–13 → +2 и т.д.

## 3. Классы и уровни (冒険者技能)

### Боевые классы (Warrior-type)
- Fighter
- Grappler (автоматически получает SCA на уровне 1)
- Fencer
- Marksman
- Battle Dancer
- Ranger (автоматически получает SCA на уровне 5)
- Scout (автоматически получает SCA на уровне 5)

### Магические классы (Wizard-type)
- Sorcerer
- Conjurer
- Priest
- Artificer
- Sage (автоматически получает SCA на уровне 5)
- Bard (spellsongs)
- Enhancer (techniques)

**Поля на листе для каждого класса:**
- Название, уровень
- Стандартное значение (Standard Value) = Уровень класса + Бонус характеристики
- Используемая характеристика

---

## 4. Боевые параметры (производные)

| Параметр | Формула |
|---|---|
| HP max | (Уровень авантюриста × 3) + VIT (значение, не бонус) |
| MP max | (Сумма уровней волшебных классов × 3) + SPR (значение) |
| HP текущие | трекер current / max |
| MP текущие | трекер current / max |
| Fortitude (стойкость) | Уровень авантюриста + бонус VIT |
| Willpower (воля) | Уровень авантюриста + бонус SPR |

### Стандартные значения для боя

| Бросок | Формула |
|---|---|
| Атака (ближняя/дальняя) | 2d6 + бонус DEX + уровень боевого класса |
| Уклонение | 2d6 + бонус AGI + уровень Fighter/Grappler/Fencer |
| Урон | бонус STR + Power оружия (по таблице) |
| Атака заклинанием | 2d6 + бонус INT + уровень волш. класса |

## 5. Снаряжение

### Оружие (поля на каждое оружие)
- Название
- Стойка (одноручное / двуручное)
- Минимальный STR для владения
- Бонус точности оружия
- Итоговое стандартное значение атаки
- Класс Power (для таблицы урона)
- Critical Value (значение d6 для крита)
- Дополнительный бонус урона

### Броня и защита
- Броня (тип, бонус защиты, бонус магзащиты, штраф)
- Щит
- Аксессуары
- Общий Defence / Evasion

### Инвентарь
- Снаряжение авантюриста (инструменты)
- Зелья, расходники (HP potions, Awakening potions, Mana crystals)
- Боеприпасы (для стрелков)
- Деньги: Gamels (стартовый бюджет — 1200 G)

## 6. Боевые способности (SCA / Combat Feats)

- Каждый персонаж получает 1 SCA при создании
- Дополнительные SCA на нечётных уровнях авантюриста (1, 3, 5, 7...)
- Поле: название + краткое описание для каждой SCA

## 7. Магия

- Magic Power Standard Value = уровень волш. класса + бонус INT
- Отдельная строка для каждого волшебного класса
- Список известных заклинаний: круг, название, MP-стоимость, дальность, время каста, эффект
- Spellsongs (Bard) и Techniques (Enhancer) — отдельные секции
