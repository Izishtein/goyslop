# Character Sheet Content — Open Questions

## Базовая информация

- Имя, раса, пол, возраст, рост/вес
- Игрок, мастер, кампания, сессия
- Опыт (текущий / потраченный / всего)
- Какие расы включаем? Все из 2.5 core + дополнения?
  - Human, Elf, Dwarf, Gnome, Tabbit, Lildraken, Runefolk, Nightmare, Shade, Garm, Wulfen, Nightmare, Centaur, Feather...

## Характеристики (能力値)

SW 2.5 использует 6 базовых:
- 筋力 STR / 敏捷 AGI / 知力 INT / 精神 SPR / 生命力 VIT / 知覚 PER

Открытые вопросы:
- Считаем бонусы автоматически из расы + возраста + роста?
- Показываем таблицу бонуса к броску рядом с каждой характеристикой?

## Классы и уровни (冒険者技能)

- Список всех доступных классов:
  Fighter, Grappler, Fencer, Shooter, Ranger, Priest, Wizard, Fairy Tamer,
  Bard, Druid, Rider, Enhancer, Duelist, Commander, Battle Dancer, Alchemist...
- Ограничение: только классы из core или из всех дополнений?
- Отображать ли growth table прямо на листе?
- Считать ли автоматически необходимый опыт для следующего уровня?

## Боевые параметры

- HP / MP (max и текущие)
- Инициатива
- Бонус к атаке / уклонению / защите для каждого класса?
- Критическое число

## Вторичные навыки (一般技能)

- Нужны ли general skills на листе?
- Как показывать модификаторы от оборудования?

## Снаряжение

- Оружие: тип, урон, точность, дальность, особые свойства
- Броня: тип, защита, магзащита, штраф
- Инвентарь: произвольный список или структурированный?
- Зелья / расходники отдельно?
- Деньги (золото / серебро / медь)?

## Заклинания

- Список по кругу и школе магии
- Фиксированный список или произвольный ввод?
- MP-стоимость, время каста, дальность — редактируемые или из справочника?
- Подготовленные заклинания vs все известные?

## Черты и способности

- Combat Feats, General Feats, Race Feats — отдельные секции?
- Автоматически добавлять расовые черты при выборе расы?

## Заметки и история

- Свободное поле для предыстории
- Связи / союзники / враги
- Личные цели

## Открытые вопросы по содержанию

- Включать ли раздел "монстры/фамильяры" для Fairy Tamer / Druid?
- Нужен ли трекер статус-эффектов (яд, паралич, etc.)?
- Tracker усталости / очков исцеления?
- Секция для стоимости содержания персонажа (жильё, еда)?
