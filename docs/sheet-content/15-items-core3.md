# SW 2.5 — Снаряжение Core Rulebook III (pp. 206–249)

Source: Core Rulebook III, Part 3 «Item Data», pp. 206–249.

Последний неразобранный кусок Core-книг. Здесь **только то, что Core III добавляет** к
спискам Core I/II — книга не переиздаёт базовый ассортимент, а дописывает к каждой
категории новые строки, в основном ранга **SS** (ранг введён в Abyss Breaker, см.
`06-equipment.md`, и Core III им пользуется вовсю).

Общие поля и формулы оружия/брони — в `06-equipment.md`, они не менялись. Здесь —
построчные данные и то новое, чего в `06-equipment.md` не было: аннотации оружия,
обозначения Stance, Ignidite/Manatite-улучшения и цены усилений Core II для SS-ранга.
Данные для маунтов (pp. 250–262) вынесены в `16-mounts.md`.

**Как получены цифры.** Названия, Min STR, Accuracy, Power и цены извлекаются текстом
(`pdftotext -layout`). **Crit Value текстом не лежит** — он нарисован кружком-значком
(⑩/⑪/⑫), ровно как круг заклинания в `13-spells-supplements.md`. Поэтому все страницы
таблиц (207–220) отрисованы в PNG (`scripts/render-pdf-pages.mjs`) и Crit Value снят
глазами. Заодно выяснилось, что текстовый слой **путает строки** в узких таблицах: у
SS-Rank Flails и SS-Rank Wrestling `pdftotext` перемешал значения между соседними
предметами. Все числа ниже сверены с картинкой, а не с текстом.

Эффекты предметов (блоки «Detailed Data», pp. 226–244) не переносятся построчно — в
приложении каталог индексный, а у каждой строки снаряжения на листе своё поле заметки.
Односложная сводка книги («Sum.») приведена в колонке «Что делает».

## Аннотации оружия (p. 206)

| Аннотация | Смысл |
|-----------|-------|
| **Stance: 1HR** | Данные для боя верхом. Если владелец едет на маунте — используются строки 1HR |
| **Slayer + X (Классификация)** | +X Extra Damage по указанной классификации монстров; классификаций может быть несколько, все складываются |
| **Type Weapon (Тип) +X/MP Cost Y** | За Y MP оружие на 10 секунд (1 раунд) наносит урон указанного типа, Extra Damage +X. Fairy Weapon-усиление на таком оружии даёт тот же тип, но всё равно только за MP; второй тип выдать нельзя |
| **Auto-Return** | Метательное само возвращается в руку сразу после броска. «Auto-Return (only on miss)» — только при промахе, при попадании падает рядом с целью |

### Обозначения Stance (легенда — Core I, p. 264; в Core III используется без изменений)

| Код | Смысл |
|-----|-------|
| `1H` / `2H` | Одноручное / двуручное |
| `1H⇄` (в книге — значок) | Одноручное, у которого сразу ниже идёт строка `2H` — то же оружие в двуручном хвате |
| `2Hs` / `2Hp` | Двуручное с двумя режимами — рубящий (slashing) и колющий (piercing); хват объявляется до броска на попадание |
| `1H*` / `2H*` | Может метаться. Данные в разделе ближнего боя — для ближнего боя, не для броска |
| `1HW` | Оружие Wrestling: надевается на руку, в этой же руке можно держать `1H/2H`-предмет |
| `1H#` / `2H#` | Не занимает рук, но для феатов и ограничений считается одноручным/двуручным |

## Ошибки книги, найденные при разборе

Не ошибки извлечения — обе стороны проверены по отрисованным страницам.

1. **Ring of Righteous Belief — две разные цены.** Сводная таблица аксессуаров (p. 224)
   даёт **30,000**, карточка предмета (p. 243) — **Base Price: 8,000**. В каталоге
   приложения стоит 8,000: карточка предмета — первичный источник цены для всех остальных
   предметов книги, и держать разнобой в одном каталоге хуже, чем выбрать одну сторону.
   Расхождение помечено прямо в строке каталога.
2. **Heart Tracker — сноска в пустоту.** У S-рангового Heart Tracker (p. 213) стоит
   «Details p. 230», но на p. 230 идут Balanced Pendulum, Daemonthresher, Golden Mattocks
   и Shock Hammer — карточки Heart Tracker в книге нет вообще. Что именно он делает,
   по Core III неизвестно; в каталоге у него только числа.
3. **B-Rank Wrestling «Bite» — без цены.** Колонка Price пустая: это не оружие для
   покупки, а данные для персонажа, у которого укус есть как часть тела (сноска «Bite is
   needed»).

## Что из этого попало в приложение

`src/data/equipment.ts` — каталог: оружие (по строкам Stance), броня, щиты и общий список
предметов с ценами. Как и каталоги заклинаний и фитов, он **индексный**: имя, ранг,
числа, цена — без текста эффектов. Пикеры на листе заполняют строку оружия/брони/щита
готовыми числами, дальше всё редактируется руками; ручной ввод никуда не делся —
базовый ассортимент Core I/II в каталог не переносился, у него нет разбора в доках.
