# SW 2.5 — Magic System & Spell Schools

Sources: GM Binder, ccxp.info overview parts 2 & 7, search results for all wizard classes.

---

## Общие принципы магии

- Волшебные классы автоматически получают **все заклинания** своего круга (level) при повышении уровня класса (~4 заклинания за круг)
- Заклинания требуют **MP** для каста
- Mako Stones (маго-камни) дают дополнительный пул MP; при исчерпании рассыпаются

### Требования для каста (зависят от класса):
- Sorcerer: голос (vocalize) + свободные руки
- Conjurer: голос + свободные руки + магический артефакт (implement)
- Priest: только голос; Holy Symbol как фокус
- Artificer: голос + Magisphere нужного размера правильно экипирована
- Fairy Tamer: голос + Fairy Gems нужного цвета; только Limited Move в тот же ход

## Магические школы

### 1. Truespeech Magic (真語魔法) — Sorcerer

- Самый высокий урон среди магических классов
- Книга I: заклинания 1–5 круга
- Книга II: заклинания до круга 10
- Примеры: [Fire Ball], [Lightning Bolt], [Ice Storm]

**Поля на листе:**
```
Sorcerer Magic Power: [Class Lv + INT mod]
Spell List:
  Lvl | Name             | MP | Range | Cast Time | Effect
  ────┼──────────────────┼────┼───────┼───────────┼───────
   1  │ [название]       │ 2  │ 10m   │ 1 action  │ ...
```

---

### 2. Spiritualism Magic (操霊魔法) — Conjurer

- Саппорт + призыв; создание нежити и големов на высоких уровнях
- Особые возможности:
  - **Animate Doll**: создание разведочной куклы (физические возможности ребёнка)
  - **Command Doll** (Lv 2): управление куклой
  - **Doll Sight** (Lv 4): видеть через глаза куклы
  - Голем-призыв и нежить (уровень 3+)
- Требует магический артефакт как фокус

---

### 3. Divine Magic (神聖魔法) — Priest

- Исцеление, поддержка, борьба с нежитью
- **Система богов**: при получении класса Priest выбирается одно божество → специализированные тематические заклинания
- Holy Symbol как фокус
- Возможности: Heal, Bless, Turn Undead, Remove Status Effects
- Только голос нужен для каста

**Примеры богов:**
- Lyphos, Tidan, Dhalkrem, Grendal (упомянуты в sources)
- Myles (Divine Chef, заклинания с тематикой готовки: [Enticing Aroma], [Adiposity])

---

### 4. Magitech / Enchantry (魔動機術) — Artificer

- Преобразование Magispheres в инструменты: ракетные сапоги, манабайки, etc.
- **Guns & Bullets**: единственный класс с огнестрельным оружием
  - Пули могут наносить урон, исцелять и др.
- Magus Arts supplement: расширение списка заклинаний (дополнительная утилита без оружия)
- Размер Magisphere = требование для определённых заклинаний

---

### 5. Fairy Magic (妖精魔法) — Fairy Tamer

- Призыв фей через самоцветы по **цвету / типу**

| Цвет / Тип | Стихия / Сфера |
|------------|---------------|
| Красный | Fire (огонь) |
| Синий | Water (вода) |
| Зелёный | Earth (земля) |
| Жёлтый | Wind (ветер) |
| Белый | Light (свет) |
| Чёрный | Dark (тьма) |
| Прозрачный / Радужный | «Fairy» (чистая мана) |

- Fairy Gems = расходный материал / инвентарный предмет
- Ограниченное движение в ход каста
- Пример атакующих заклинаний: Fire → [Fire Blast], Water → [Chill Rain]

---

### 6. Nature Magic (自然魔法) — Druid (Epic Treasury)

- Призыв духов природы для боя
- **Symbols of Beneficence**: мощные зоны баффов/защитных заклинаний для союзников

---

### 7. Daemon Magic / Summoning Arts (召喚術) — Abyss Gazer / Warlock (Abyss Breaker)

Три типа заклинаний:
1. **Трансформация тела/оружия**: усиление себя даемонической силой
2. **Атаки из Daemon World**: прямые атаки через портал
3. **Прямой призыв Daemon**: с риском потери контроля

- Требуются «banishment items» или специальная подготовка
- Контракт с Gate Imps

---

### 8. Book Magic (書物魔法) — Bibliomancer (Tyrant Crypt)

- Магия через тома и книги
- Подробности отсутствуют в EN-источниках

---

### 9. Nature / Geomancy (地脈術) — Geomancer (Mage Arts)

- Не использует MP
- Minor Action для размещения Geographs
- Накопление Qi окружающей среды
- Aspects = случайные зональные эффекты (урон / дебаффы / исцеление / баффы)

---

### 10. Spellsongs (呪歌) — Bard (Core II)

Не стандартные заклинания, но отдельная система:
- **Spellsong** (напев): поддерживаемый эффект
- **Rhythm** (ритм): накопление ресурса
- **Finale** (финал): мощный финальный эффект после накопленного Rhythm

---

### 11. Techniques (技術) — Enhancer (Core II)

- Физическое усиление способностей
- Аналог Bard, но для тела

---

### 12. Essence Weavings — Dark Hunter (Abyss Breaker)

- Манипуляция метательным оружием
- Самоусиление за счёт VIT

---

## Структура секции заклинаний на листе

### Для каждого волшебного класса:

```
┌── [Класс] Magic ──────────────────────────────────┐
│ Magic Power SV: [Class Lv + INT mod]              │
│ MP Contribution: [Class Lv × 3]                   │
├───────────────────────────────────────────────────┤
│ # │ Название        │ MP │ Дальн │ Время │ Эффект │
│ 1 │                 │    │       │       │        │
│ 2 │                 │    │       │       │        │
│ … │                 │    │       │       │        │
└───────────────────────────────────────────────────┘
```

### Для Fairy Tamer: дополнительно
```
Fairy Gem Stock:
  Fire:  □□□   Water: □□□   Earth: □□□
  Wind:  □□□   Light: □□□   Dark:  □□□
  Fairy: □□□
```

### Для Priest: дополнительно
```
Deity: [________________]
Deity-specific spells: (отдельный подраздел)
```

### Для Artificer: дополнительно
```
Magisphere inventory:
  Size S: □□□   Size M: □□□   Size L: □□□
Bullets:
  Type │ Qty │ Effect
  ─────┼─────┼──────────
```

### Для Bard:
```
Spellsongs:
  Name │ Rhythm Cost │ Effect
  ─────┼─────────────┼────────

Current Rhythm: [___]
Finale: [________________]
```
