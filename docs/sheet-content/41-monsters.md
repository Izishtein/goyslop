# Монстры — Monstrous Lore, Part 2 «Monster Data» (pp. 73–224)

Источник: `Sword World 2.5 - Monstrous Lore.pdf`. Каталог — `src/data/monsters/monsters.json` (генерируется `scripts/parse-monsters.mjs`), тип — `src/data/monsters/types.ts`, экран — вкладка «Монстры» справочника (`MonstersReference.tsx`).

## Что в каталоге: 375 карточек

Barbarous 86 · Animals 47 · Plants 19 · Undead 43 · Constructs 27 · Magitech 31 · Mythical Beasts 28 · Fairies 35 · Daemons 39 · Humanoids 20. Книга сама собрала сюда монстров из Core I–III и дополнений («First Appearance»: `CR I p. 397`, `KF`, `VC`, `New`…), отдельные бестиарии не нужны.

Не вошло (отдельный формат страниц, следующая пачка 6.1б): Golem Data pp. 225–235, Familiar Data pp. 236–243, «Common Abilities of …» (Undead, Constructs/Magitech, Fairies — общие способности категории, в карточках отдельных монстров опущены), «Modifying Humanoid Monsters» p. 223.

## Как читается PDF

Страницы двухколоночные; `pdftotext -layout` переплетает колонки построчно, а установленная версия не умеет обрезать область. Поэтому `scripts/pdf-columns.mjs` берёт позиции текстовых фрагментов из pdf.js (`pdfjs-dist`, ставится `npm install --no-save`), делит страницу по середине и читает колонки сверху вниз; пробел между фрагментами ставится только при настоящем зазоре (иначе числа рассыпались бы: «1 1»), красная строка абзаца определяется по сдвигу x. Карточка начинается строкой над «Intelligence:» (`<уровень> <имя> <источник>`), классификация — по диапазону страниц из оглавления (заголовок раздела — картинка).

## Что разобрано в каждой карточке

Уровень (у шаблонных монстров «1+»/«8+» — `levelPlus`), имя, источник, классификация, страница, Intelligence/Perception/Disposition, Soulscars (метка бывает «Soulscars» и «Souls.»), Language, Habitat, Rep/Weak (две цели Monster Knowledge: «что это» и «слабое место»), Weak Point (метки «Weak Point», «Weak Points», «W. P.», «W.P.»), Initiative, Movement Speed, Fortitude/Willpower в виде «значение (фикс.)», таблица секций (стиль атаки, точность, урон 2d±X, уклонение, защита, HP, MP — по строке на часть тела), `Sections: … Main Section:`, уникальные навыки (значок действия ◯ ► 🗨 ⏩ △, название, текст, секция «●Body/Wing…»), таблица добычи (бросок 2d → предмет), описание абзацами.

## Грабли

- **Имя стиля атаки переносится вокруг чисел**: «Weapon (Upper / 12(19) 9 85 - / Body)». Числа ищутся первыми, слова между двумя группами чисел делятся по скобкам (закрывающая — предыдущей строке, остальное — следующей).
- **Одна карточка не читается текстовым слоем** — Domsva (p. 167): числа строк перемешаны по вертикали. Строки заданы вручную (`ROW_OVERRIDES`) по отрисованной странице.
- **Шаблонные монстры** (Revenant, High Revenant, Magireplica): значения — знаки «※+2», «※/※», хранятся как есть (`{raw}`), стиль атаки у Magireplica — «※».
- **Нет блока Loot** у всех фей; **нет Description** у второй формы (Dragon Form, Daemon Form, Monstrous Form) — описание общее с первой формой.
- **Опечатки книги сохранены как напечатано.** Фиксированное значение везде = значение + 7, кроме пяти мест: Carnage Table (Fortitude 4 (21), Willpower 3 (20)), Crash Bear (Fortitude 2 (19)), Diablo Captain (Daemon Form) Bite (Head) Evasion 19 (25), Varg Bite Accuracy 8 (16). Они перечислены в `monsters.test.ts`, чтобы ошибка разбора не пряталась среди них.

## Язык

Перевода монстров нет ни в одном файле `files/`, поэтому описания и навыки — английский текст книги на обоих языках интерфейса (это сказано в примечании вкладки). Подписи, названия классификаций и фильтры переведены.

## Хранение

Каталог ≈ 1 МБ, поэтому это отдельный чанк (`loadMonsters()` — динамический `import()`), он тянется при первом открытии вкладки, а не в основном бандле.
