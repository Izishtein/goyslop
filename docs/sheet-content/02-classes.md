# SW 2.5 — Classes (Полный список классов / 冒険者技能)

Sources: ccxp.info, GM Binder, fujimi-trpg-online supplement list, WebSearch results,
Japanese Wikipedia, ameblo race/class guide.

Итого классов после Abyss Breaker: **23 класса** (+ классы Bubble Worlds и Dragon Bone Saga).

---

## Стоимость классов (XP)

- **Major-класс**: 1 000 XP за каждый уровень
- **Minor-класс**: 500 XP за 1-й уровень, затем 1 000 XP за каждый следующий

Adventurer Level (уровень авантюриста) = наивысший уровень среди всех освоенных классов.

---

## Warrior-Type Classes (Боевые классы) — 5 классов

Вносят вклад в **Accuracy Check**, **Evasion Check**, **Extra Damage**.
Формулы:
- Accuracy: 2d6 + DEX modifier + Warrior Class Level
- Evasion: Warrior Class Level (кроме Marksman) + AGI modifier
- Extra Damage: Warrior Class Level + STR modifier

| Класс | Тип | Ключевая характеристика | Книга | Описание |
|-------|-----|------------------------|-------|----------|
| **Fighter** | Major | STR, VIT | Core I | Тяжёлое вооружение и броня, основной танк и дамагер |
| **Grappler** | Major | STR, DEX | Core I | Борьба и безоружный бой; Chain Attack feat; уникальное оружие; броня как у Fencer |
| **Fencer** | Minor | DEX, AGI | Core I | Финессовый боец; STR делится на 2 (округл. вверх) для расчёта минимальной STR снаряжения; повышенный шанс крита с любым оружием |
| **Marksman** | Minor | DEX | Core I | Дальнобойный бой; не вносит вклад в Evasion от зон |
| **Battle Dancer** | Minor | DEX, AGI | Battle Mastery | +1 Evasion/Accuracy/Damage за уровень; танцевальные манёвры; может носить оружие Grappler; броня как у Grappler; дополнительная SCA из ограниченного списка на уровне 1 |

## Wizard-Type Classes (Волшебные классы) — 8 классов

Вносят вклад в **Magic Power** и **MP**.
Формулы:
- Magic Power: 2d6 + INT modifier + Wizard Class Level
- MP max: (Сумма всех Wizard Class Levels × 3) + SPR (значение, не бонус)

| Класс | Тип | Магическая школа | Книга | Описание |
|-------|-----|-----------------|-------|----------|
| **Sorcerer** | Major | Truespeech Magic (真語魔法) | Core I | Высокий урон; получает все заклинания автоматически при повышении уровня (~4/уровень); требует голос + свободные руки |
| **Conjurer** | Major | Spiritualism Magic (操霊魔法) | Core I | Призыв, анимация кукол (разведка через доску), создание нежити/големов на высоких уровнях; фокус — магический артефакт |
| **Priest** | Major | Divine Magic (神聖魔法) | Core I | Исцеление, отражение нежити, благословения; выбирает одно божество при получении класса; Holy Symbol как фокус |
| **Artificer** | Major | Magitech (魔動機術) | Core I | Магитехника: magispheres → инструменты (ракетные сапоги, манабайки); единственный класс с пушками/ружьями и пулями; фокус — Magisphere нужного размера |
| **Fairy Tamer** | Major | Fairy Magic (妖精魔法) | Core II | Призыв фей через самоцветы по цветам/типам: земля, огонь, вода, ветер, свет, тьма, «фея»; ограниченное движение при касте |
| **Druid** | Major | Nature Magic (自然魔法) | Epic Treasury | Призыв духов природы; создаёт Symbols of Beneficence (мощные баффы/защитные заклинания для союзников) |
| **Abyss Gazer** (Warlock) | Major | Summoning Arts / Daemon Magic | Abyss Breaker | Контракты с Gate Imps для призыва Daemons; три типа заклинаний: трансформация тела, атаки из Daemon World, прямой призыв; риск потери контроля |
| **Bibliomancer** | Major | Book Magic | Tyrant Crypt | Магия через книги/тома; подробности не задокументированы в EN-источниках |

## Поля на листе для раздела «Классы»

Для каждого класса нужна строка:

```
[ Название класса ]  [ Тип: W/M/O ]  [ Уровень ]  [ Standard Value (SV) ]  [ Ключевая характеристика ]
```

**Standard Value** = Class Level + Ability Modifier (соответствующей характеристики)

**Дополнительно для каждого волшебного класса:**
```
[ Magic Power SV = Class Level + INT modifier ]
[ MP contribution = Class Level × 3 ]
```

## Прогрессия и ограничения

- Все классы дают доступ к снаряжению ранга B.
- Для снаряжения ранга A, S — нужна соответствующая SCA (Combat Feat).
- Fencer: эффективная STR для снаряжения = STR/2 (округление вверх).
- Marksman не вносит вклад в Evasion (специфика механики зон).
- Некоторые расы запрещают определённые классы (см. 01-races.md).
