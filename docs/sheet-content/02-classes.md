## Стоимость классов (XP)

- **Major-класс**: 1 000 XP за каждый уровень
- **Minor-класс**: 500 XP за 1-й уровень, затем 1 000 XP за каждый следующий

Adventurer Level (уровень авантюриста) = наивысший уровень среди всех освоенных классов.

## Warrior-Type Classes (Боевые классы) — 5 классов

Вносят вклад в **Accuracy Check**, **Evasion Check**, **Extra Damage**.
Формулы:
- Accuracy: 2d6 + DEX modifier + Warrior Class Level
- Evasion: Warrior Class Level (кроме Marksman) + AGI modifier
- Extra Damage: Warrior Class Level + STR modifier

| Класс | Тип | Ключевая характеристика | Книга | Описание |
|-------|-----|------------------------|-------|----------|
| **Fighter** | Major | STR, VIT | Core I | Тяжёлое вооружение и броня, основной танк и дамагер |
| **Grappler** | Major | STR, DEX | Core I | Борьба и безоружный бой; Chain Attack feat; уникальное оружие; броня как у Fencer |
| **Fencer** | Minor | DEX, AGI | Core I | Финессовый боец; STR делится на 2 (округл. вверх) для расчёта минимальной STR снаряжения; повышенный шанс крита с любым оружием |
| **Marksman** | Minor | DEX | Core I | Дальнобойный бой; не вносит вклад в Evasion от зон |
| **Battle Dancer** | Minor | DEX, AGI | Battle Mastery | +1 Evasion/Accuracy/Damage за уровень; танцевальные манёвры; может носить оружие Grappler; броня как у Grappler; дополнительная SCA из ограниченного списка на уровне 1 |

## Wizard-Type Classes (Волшебные классы) — 9 классов

Вносят вклад в **Magic Power** и **MP**.
Формулы:
- Magic Power: 2d6 + INT modifier + Wizard Class Level
- MP max: (Сумма всех Wizard Class Levels × 3) + SPR (значение, не бонус)

## Поля на листе для раздела «Классы»

Для каждого класса нужна строка:

```
[ Название класса ]  [ Тип: W/M/O ]  [ Уровень ]  [ Standard Value (SV) ]  [ Ключевая характеристика ]
```

**Standard Value** = Class Level + Ability Modifier (соответствующей характеристики)

**Дополнительно для каждого волшебного класса:**
```
[ Magic Power SV = Class Level + INT modifier ]
[ MP contribution = Class Level × 3 ]
```

## Geomancer — полная механика (Magus Arts, pp. 17–28, подтверждено 2026-07-09)

**Тип:** Other-Type Minor Class. Проверенные навыки-пакеты: Search check + Meteorology check → "Geomancer Observation Check Package" (CR I p.107, 114).

**Ключевые термины:**
- **Domain Aspects (Aspects)** — техники Geomancer'а, не магия (не détectируются [Sense Magic]/[Mana Search], не подвержены [Metamagic/\*\*]). 1 Aspect за уровень класса (число известных Aspects = уровень класса). Делятся на 3 типа: **Heavenly**, **Earthly**, **Spirit** — каждый расходует свой тип Qi.
- **Qi Points** — 3 типа (Heavenly/Earthly/Spirit Qi), копятся через **Geograph** (аксессуар типа "Accessory: Any", не занимает руки). Пока Geograph развёрнут — по 1 очку каждого типа каждые 10 сек (мгновенно +1 каждого при развёртывании в бою). Максимум зависит от модели Geograph. При сворачивании Geograph все накопленные Qi теряются.
- **Geograph** — нужно "развернуть" (Minor Action), пока развёрнут — передвижение только Limited Move. Разворачивать и сворачивать в один ход нельзя. Список моделей (Domain Range / лимиты Qi / цена):

| Geograph | Domain Range | Heavenly | Earthly | Spirit | Цена | Условие |
|----------|--------------|----------|---------|--------|------|---------|
| Novice | 2–3 зоны (10м) | 2 | 2 | 2 | 200 G | — |
| Celestial | Все зоны (20м) | 3 | 2 | 2 | 500 G | — |
| Tectonic | Все зоны (20м) | 2 | 3 | 2 | 500 G | — |
| Spiritual | Все зоны (20м) | 2 | 2 | 3 | 500 G | — |
| Master | Все зоны (20м) | 3 | 3 | 3 | 2,000 G | Geomancer Lv5+ |
| Sky Breaker | Все зоны (30м) | 2 | 4 | 4 | 3,000 G | Geomancer Lv5+ |
| Earth Shaker | Все зоны (30м) | 4 | 2 | 4 | 3,000 G | Geomancer Lv5+ |
| Soul Render | Все зоны (30м) | 4 | 4 | 2 | 3,000 G | Geomancer Lv5+ |
| Supreme ("Taiji Geograph") | Все зоны (50м) | 4 | 4 | 4 | 10,000 G | Geomancer Lv10+ |

**Механика применения Aspect:**
- Использование — Minor Action; не более 1 Aspect за ход (даже если разного типа Qi).
- Цель определяется **случайно** среди ВСЕХ персонажей (включая самого Geomancer'а и союзников) в радиусе действия Geograph — выбор цели не контролируется игроком. Success Value = 0, Resistance: Can't.
- Эффект применяется в конце хода Geomancer'а, длительность "Instant" или "10 сек (1 раунд)"; действует, пока Geograph развёрнут, цель переопределяется в конце каждого хода.
- Можно **отменить (Cancel)** применение конкретного Aspect на выбранной цели вместо применения.
- Эксклюзивные Combat Feats: **[Spreading Triad]** (Geomancer Lv1+, аспект бьёт по 2 случайным целям) и **[Dividing Triad]** (Geomancer Lv3+, можно отменить часть эффектов у цели, оставив нужные).
- Пример Aspect: *Heavenly Domain: Descending Thunder* — Cost: Heavenly Qi 1–4, Duration Instant, эффект: фиксированный урон "потрачено Heavenly Qi × 2" (тип Lightning).
- Полный список Aspects (десятки штук по 3 типам, некоторые с требованием Geomancer Lv5/10) — не транскрибирован построчно (низкий приоритет, объёмный список); при необходимости взять из `files/Sword World 2.5 - Magus Arts.pdf`, pp. 23–28.

**Для листа персонажа:** нужны поля Geograph (модель, Domain Range, лимиты Qi по 3 типам), текущие Qi Points (3 счётчика), список известных Aspects (= уровень класса), трекер "Geograph развёрнут/свёрнут".

## Tactician — полная механика (Magus Arts, pp. 16, 29–35, подтверждено 2026-07-09)

**Тип:** Other-Type Minor Class. Проверенный навык: Initiative check (CR I p.105) — Tactician Level добавляется к Initiative. Требует **Strategist Insignia** (аксессуар) для использования Stratagems/Maneuvers; голос обязателен (не убирается даже Nightmare [Alternate Form]); работает только в бою.

**Stratagems** — командные баффы на **всех союзников** в "commanding area" (кроме самого Tactician'а), без затрат MP, Minor Action, не чаще раза в раунд:
- Радиус commanding area зависит от **Adventurer Rank** самого Tactician'а:

| Adventurer Rank | Commanding Area |
|---|---|
| None | 1 зона (5м) |
| Dagger | 2–3 зоны (10м) |
| Rapier | Все зоны (20м) |
| Broad Sword | Все зоны (30м) |
| Flamberge | Все зоны (40м) |
| Sentinel | Все зоны (50м) |
| Hyperion | Все зоны (100м) |
| Sword of Genesis | Все зоны (200м, +100м за каждую ★) |

- Условия действия: цель — союзник, слышит голос Tactician'а на известном ему языке, интеллект Low/Average/High (не выше), не сам Tactician. Маунт/питомец союзника — тоже валидная цель, если наездник удовлетворяет условиям.
- Длительность 10 сек (1 раунд), эффект не пропадает при выходе цели из зоны или потере сознания самим Tactician'ом (но пропадает, если сама цель теряет боеспособность).
- 5 типов: **Attack** (физ. урон), **Evasion**, **Defense**, **Resistance**, **Inspirational** (не относится к другим, разрешает Stratagem другого типа того же/выше ранга в следующем раунде).
- 5 рангов (1–5): бой всегда начинается с Rank 1. Чтобы использовать Rank 2+, нужно было использовать Stratagem в предыдущем раунде: **того же типа → +1 к рангу**, **другого типа → -1 к рангу** (но Rank 1 любого типа доступен всегда); Inspirational — особый случай (не понижает при смене типа, даёт +1 ранг любого типа на следующий раунд).
- Не стакаются — при повторном наложении цель выбирает, оставить старый эффект или заменить новым.

**Maneuvers** — техники **на самого Tactician'а** (в отличие от Stratagems), Instant, оплачиваются из **Edge**:
- **Edge** — очки, копятся только в бою (сбрасываются в 0 при завершении боя или потере сознания Tactician'ом), не расшариваются между разными Tactician'ами. Копятся от использования Stratagems/Maneuvers/предметов/Combat Feats с пометкой "Edge Accumulation: +X" (0, если у Stratagem не было валидных целей).
- 1 Maneuver за раунд (плюс 1 Stratagem — то есть по одному того и другого за раунд).
- Число известных Stratagems+Maneuvers = уровень класса Tactician (по одному на уровень); некоторые требуют минимальный уровень (1st/5th Level Tactician Required и т.д.); часть Maneuvers требует предварительного изучения других Maneuvers.
- Синергия: Stratagems/Maneuvers можно исполнять одновременно со Spellsong или [Battle Hymn] (Bard/Priest).

**Для листа персонажа:** нужны поля Edge (текущее значение), список известных Stratagems/Maneuvers с рангом/типом, трекер "Stratagem использован в этом раунде + его тип/ранг" (для расчёта доступных рангов в следующем раунде), Strategist Insignia в снаряжении.

## Druid — полная механика (Monstrous Lore, pp. 10, 16–27, подтверждено 2026-07-09)

**Тип:** Wizard-Type Major Class. Магическая школа — **Nature Magic**. Проверенный навык: Spellcasting Check (CR I p.108). Runefolk не могут стать Druid (не видят духов).

**Ключевые термины:**
- **Spirits** — при касте появляется полупрозрачное животное/растение, которое и производит эффект. Не может быть атаковано, длится всё время эффекта (если не Instant). Runefolk не видят духов, но получают их эффекты.
- **Staff of the Sacred Tree** — обязательный фокус (Stance: 1H, 100 гамелов; любой Staff можно доработать за 100 г). Без него Nature Magic недоступна.
- **Условия каста:** вокализация обязательна (поэтому Lykant в [Beast Form] может кастовать, а Nightmare в [Alternate Form] — даже без вокализации); передвижение ограничено Limited Move; металлическая броня — Magic Power -4 (мин. 0), небронированная/немeталлическая — без штрафа.
- **Symbolic Lore** — особая категория самых мощных спеллов (**[Big Defender]**, **[Multiple Actor]**, **[Plants Gift]** и их варианты). Жёсткие ограничения: цель должна иметь **Symbol of Beneficence** (предмет-обязательство, создаётся Druid'ом за 1 час или 100 г у NPC, действует пожизненно, персонажу нужен даже для получения эффекта самому себе); одно и то же название Symbolic Lore действует на персонажа только 1 раз в день; не более одного применения каждого названия за раунд; несовместимо с [Metamagic] в любом виде; маунт получает эффект только вместе с наездником, если у наездника есть Symbol.
- **Natural Power / Natural Power II** (MP0) — даёт временное MP (Power 10/30) только для каста Nature Magic, только в природной среде (CR I p.101), сгорает в конце хода кастера.
- Некоторые заклинания определяют физический урон броском 2d по таблице (нельзя менять броском [Sword's Grace/Change Fate]); такой урон считается "Magic Weapon Damage", не рубящим/дробящим.

**Заклинания (Nature Magic Data, pp. 20–27):** **60 заклинаний** (4 на каждом из 15 уровней; прежняя оценка «~59» была прикидкой), MP-диапазон 0–30 (Natural Haven, Blaze Shower — топовые). Именование `[Имя/Животное]` — совпадающие "Имя" не суммируются на одной цели. **Построчный список — `13-spells-supplements.md`** (в приложении: `src/data/spells/nature.ts`).

**Снаряжение (Additional Items, p.54):** Symbol of Beneficence (100 г), Raw Sacred Wood (100 г, материал), 3 ранга боевых посохов-Staff of the Sacred Tree (Oak/Iron Bands/Dense Oak Staff, B/A/S-ранг).

**Для листа персонажа:** поле "Staff of the Sacred Tree" (экипирован?), список известных заклинаний Nature Magic (по уровню класса), трекер Symbols of Beneficence (кому создан, дата последнего эффекта каждого названия — для лимита раз/день).

## Daemonologist (Summoner / Daemon Tamer) — полная механика (Monstrous Lore, pp. 12, 28–54, подтверждено 2026-07-09)

**Тип:** Wizard-Type Major Class. Магическая школа — **Summoning Arts**. Даёт разговорный Daemonic и чтение Arcana. Проверенные навыки: Spellcasting Check, **Banish check** (свой, см. ниже). Lykant в [Beast Form] не может действовать как Daemonologist (не может говорить на Daemonic).

**Gate Imp** — уникальный спутник-конструкт, появляется при получении класса, по одному на Daemonologist'а. Хранится в **Imp Seal** (обязательный предмет, 5 моделей: Summoner's Tattoo/Emblem, Devil Arm, Small/Large Daemon Vessel, Daemon Seminarium — у каждой свои бонусы/штрафы к Spellcasting/Banish check). Пока не защищён Imp Seal'ом и подвергается урону — урон/эффекты идут на самого Daemonologist'а (Evasion=0, Fort/Will = как у хозяина, Defense=0). Гибель/потеря Gate Imp = потеря доступа к Summoning Arts до нового контракта (1 час ритуала).

**Призыв Daemon (Abyss Gate):**
1. **Формирование Abyss Gate** — Minor Action (Major Action, если на Daemonologist'е металл. броня либо небронированная с Min STR ≥10), движение → Limited Move.
2. **Призыв** — Minor Action, требует Summoning Sacrifice (обязательное подношение, часть — Loot с монстров, часть покупается), MP = Monster Level × 2. Лимит: Monster Level ≤ Adventurer Level кастера (не Daemonologist Class Level!), один Daemon одновременно, Daemon должен иметь подготовленный Daemon Action Chart.
3. **Действия Daemon'а** — по **Daemon Action Chart** конкретного Daemon'а: 1d roll → таблица результатов (Target/Range/Action/Success Value/Damage). Действие можно **отменить** сразу после броска, потратив MP = Monster Level (нужен физически экипированный/удерживаемый Imp Seal, Daemonologist в сознании).
4. **Banishment** — **Banish check** (Standard Value = Daemonologist Class Level + INT modifier, оппонент — Willpower Daemon'а) ИЛИ **Exorcism** (бой на добивание HP=0, без Retry, без Loot). Если Daemonologist Class Level ≥ Monster Level Daemon'а — авто-успех через **Banish Tribute** (расходник, цена по таблице) или обычная проверка без штрафа; если ниже — Banish Tribute обязателен, проверка с бонусом +4. До 6 попыток (10 минут каждая) в течение часа, иначе Daemon вырывается на свободу и Abyss Gate стабилизируется → рождает Shallow Abyss (угроза = Adventurer Level+2 кастера) + штрафной титул Infamy (Malicious Observer 50 Disgrace → Abyssal Amplifier 100 → Daemon's Sentinel 150 → Bearer of Vices 200→250+★, снимается через Reputation offset или закрытие Shallow Abyss).
5. Успешный Banish check/Tribute возвращает потраченное на призыв MP (не сверх максимума, не возвращается при частичной оплате Mako Stone).

**Daemon Seminarium** — гуманоид с имплантированным [Daemon's Seed] (заклинание Summoning Arts), нелегальный ритуал (4 уровня Infamy при обнаружении), со временем становится полностью лояльной марионеткой (стадии по дням — недели/месяцы/годы), может использоваться как Imp Seal (+1 Spellcasting, +2 Banish check) и как замена Banish Tribute (стоимость = дни × 50 г).

**Список призываемых Daemon'ов (List of Summonable Daemons, p.39+):** таблица по Monster Level (1–9+, полностью не выписана) с колонками Summoning Sacrifice (цена), Banish Tribute Cost, Willpower, страница Daemon Action Chart, страница Monster Data.

**Заклинания (Summoning Arts Data, pp. 40–45):** **46 заклинаний** (по 3 на уровень, на 2-м — 4), MP 1–50 (топовые: [Soul Sacrifice] — превращение в Doppelganger, [Daemon's Legion] — армия Daemon'ов с ресурсом "Daemon Might", [Lethal Dimension]). **Построчный список — `13-spells-supplements.md`** (в приложении: `src/data/spells/summoning.ts`).

**Для листа персонажа:** поля Gate Imp (есть/потерян), Imp Seal (модель, экипирован), текущий призванный Daemon (имя/уровень/оставшееся MP на изгнание), список известных заклинаний Summoning Arts, счётчик Infamy/Disgrace, список Daemon Seminarium (если есть).

## Dark Hunter — полная механика (Abyss Breaker, pp. 16, 28–35, подтверждено 2026-07-09)

**Тип:** Other-Type Minor Class. Механика — **Essence Weaving** (не магия: не засекается [Sense Magic]/[Mana Search], не подвержена [Metamagic], не снимается [Dispel Magic]/Grassrunner-способностью, только [Wordbreak]/[Perfect Cancellation]/Evocation [Dispel Needle]). Проверенный навык: Monster Knowledge check, ограниченный Daemons (авто-определение "Daemon или нет").

**Mental Power** = Dark Hunter Class Level + SPR modifier — аналог Magic Power, определяет силу Essence Weaving.

**1 Essence Weaving за уровень**, обязательный выбор (нельзя отложить), список — единый (не по школам), некоторые требуют Class Level 5/10 или другую Weaving как пререквизит.

**3 типа:**
- **◯ Passive** — постоянный эффект только на самого Dark Hunter.
- **⏩ Minor Action** — Success Value всегда "0" (без проверки), можно использовать многократно за ход (но одноимённые не стакаются); Cost в HP: фиксированный (напр. "2") или **"1d"** (бросается сразу при объявлении, нельзя отменить по результату).
- **► Major Action** — требует проверку (Mental Power как Standard Value), Cost = результат **2d** броска проверки (авто-провал = Cost 0; "2d(X)" — Cost капается на X).

Оплата всегда **HP** (не MP), не заменяется предметами/эффектами снижения MP-стоимости; можно уйти в 0 и ниже (Death Check), [Indomitable] спасает от потери сознания. Активные Weaving с длительностью можно отменить самому (Minor Action).

**Soul Tethers** — нематериальные ауры-нити у части способностей (видны окружающим, нельзя перерезать физически).

**Специализация:** метательное оружие (Thrown Weapons, см. `06-equipment.md`) — большинство активных Weaving усиливают именно броски. [Essence Focus] (пример из книги) — Minor Action, 1d HP, Accuracy броска +1 (+2 против Daemon/Undead), 30 сек.

**Для листа персонажа:** поле Mental Power (=Class Level+SPR mod), список известных Essence Weavings (~28 в книге) с их Cost/типом, счётчик активных длительных эффектов.

## Bibliomancer — полная механика (Tyrants Crypts, pp. 14–19, подтверждено 2026-07-09)

**Тип:** Wizard-Type Major Class. Магическая школа — **Arcane Magic** (Magic Power = Bibliomancer Class Level + INT modifier). Даёт разговорный/письменный Arcana. Проверенные навыки: Spellcasting Check, Literature Check (CR I p.107). Lykant в [Beast Form] не может кастовать. В Background-таблицах может **заменять Sorcerer или Conjurer** там, где они прописаны (Detailed Creation).

**Ключевое отличие от других школ:** заклинания **не даются автоматически по уровню класса** — каждое нужно отдельно **купить или найти** и "освоить" (master).

**Grimoire** — обязательный фокус (Stance: 1H). При каста сам "взлетает" и обводится пальцем — обе руки свободны одновременно (в отличие от других школ, где фокус в руке всё время занимает слот). Можно держать по одному Grimoire в каждой руке, но заклинание кастуется только через один за раз; Grimoire может по совместительству быть оружием/щитом (эффекты складываются, но два "щитовых" эффекта не стакаются — общее правило CR I). Использование чужого/найденного Grimoire без собственной практики = каст только через Emergency Slot (ниже).

**Получение заклинаний:**
- **Покупка у Guild of Arcane Manuscripts** — по рангу (1–5), цена 500/1500/3000/6000/12000 г; доступно только если ранг ≤ разрешённый текущими слотами; осваивается сразу.
- **Находка во время приключений** — можно продать гильдии (если уже проанализировано рынком — за половину цены покупки; если совсем новое — за двойную базовую цену по рангу) или оставить себе непроданным, чтобы кастовать через Emergency Slot без "освоения". Анализ ещё не изученного грimoire гильдией занимает 3 дня/1 неделю/2 недели/3 недели/1 месяц (ранг 1–5). Если при продаже ранг заклинания ≤ разрешённого по слотам — Bibliomancer получает результат анализа бесплатно (обучается).

**Слоты (Spell Slot Table, level 1–15):**

- **Prepared Slots** — фиксированное число ячеек по рангу; кастуются как обычная магия (можно Minor Action/Combat Preparation); замена заклинания в ячейке требует времени по рангу нового заклинания (1/2/3/6/12 часов для ранга 1–5). Более низкий ранг можно поставить в слот более высокого ранга.

При каждом Critical Failure значение перебрасывается заново (не дублирует прошлое, не дублирует сессию). У нескольких Bibliomancer'ов в группе — значения независимые, не переносятся между сессиями.

**Не задокументировано (эмбарго на полную книгу, доступна только 20-стр. Preview):** сам список заклинаний Arcane Magic (Arcane Magic Data/List, было бы на pp.20+), 8 новых Work Skills, Dig Arts, Random Tomb Creation Rules, Magic Items, ~80 новых монстров.

**Для листа персонажа:** поля Prepared Spell Slots (по рангам, что в каждом), Emergency Slot rank cap, Critical Failure Value (сбрасывается в начале сессии), список изученных/освоенных Arcane Magic отдельно от неосвоенных найденных.

## Rider — полная механика (Core Rulebook III, pp. 84–106, подтверждено 2026-07-09)

**Тип:** Other-Type Minor Class. Владельцы уровней класса называются "Jockey". Проверенные навыки: First Aid, Tumble, **Riding** (SV = Rider Lv + AGI mod), **Weakness** (SV = Rider Lv + INT mod, определяет слабое место Mount'а во время Combat Preparation), Cartography, Monster Knowledge (только определяет тип монстра, не даёт Weak Point — если есть уровни Sage выше Rider, использовать Sage).

**Mount (маунт)** — животное/мифический зверь/магитех-транспорт. Классификация: **Animal** (дешёвые, простые), **Mythical Beast** (летающие/многосекционные, редкие, высокий Appropriate Level), **Magitech** (мотобайки/машины — не имеют воли, не нуждаются в еде, требуют 1 MP на упаковку/распаковку в сферу).

**Владение:** без класса Rider можно ездить только на Horse/War Horse/Minibike/Manabike (Mount Level = минимальный Appropriate Level). С классом — можно ездить на любом Mount, если Rider Lv ≥ Appropriate Level маунта; **Mount Level = Adventurer Level Jockey'я** (не выше макс. Appropriate Level маунта). Аренда — через **Mount Contract/Sphere** у Rider's Guild (бесплатно после покупки контракта, по одному контракту на тип маунта одновременно); покупка — **Proprietary Contract/Sphere** (+10 Max HP всем секциям маунта, не нужно возвращать, можно превратить в статуэтку размером с ладонь через Mount Reduction Tag для переноски).

**Отличия Jockey от простого наездника:**
| | Свои действия | Команды маунту |
|---|---|---|
| Обычный наездник | Да (но обе руки заняты поводьями) | Нет |
| Jockey | Да (одна рука свободна) | Да |

Jockey садится/спешивается Minor Action (обычный наездник — Major Action). Jockey получает **Stunts** — по одному при каждом уровне Rider (включая первый), некоторые требуют Rider Lv 5/10+ или другой Stunt как пререквизит; обычно не требуют MP (кроме отдельных исключений типа [Intimidation] — 5 MP маунта). Всего в Core III ~30 Stunts (♦️/⏩/► типы, как Combat Feats/Essence Weaving).

**В бою:** Rider и Mount действуют в одной позиции, каждый — отдельная цель для атак/эффектов (как многосекционный монстр), но иногда считаются единым персонажем (блокирование движения, Throw-атаки, "Area: Breakthrough") или раздельным (Target: 1 Entire Character/Caster). Обычный наездник не может отдавать маунту Major Action; Jockey может. При потере сознания/падении наездник насильно спешивается.

**Для листа персонажа:** поля Mount (тип, Appropriate Level, статуэтка да/нет), Mount Contract/Proprietary Contract, список известных Stunts (~1 за уровень Rider), трекер "маунт оседлан/спешен".

**Данные маунтов** (17 штук по уровням и секциям, вооружение маунта, переноска) — `16-mounts.md`; на листе они уже есть отдельной секцией. **Списка Stunts построчно ещё нет** — Core III pp. 84–106, это единственное, чего классу Rider на листе не хватает.

## Alchemist — полная механика (Core Rulebook III, pp. 107–113, 190–198, подтверждено 2026-07-09)

**Тип:** Other-Type Minor Class. Даёт разговорный/письменный Magitech язык. Проверенные навыки: **Evocation check** (SV = Alchemist Lv + INT modifier), Insight, Literature, Herbology (объединены в "Alchemist Knowledge Check Package").

**Evocations** — способности класса (**не магия**: не засекаются [Sense Magic], не снимаются [Dispel Magic], но снимаются [Wordbreak]/[Perfect Cancellation]; [Metamagic] не работает, а [Targeting]/[Hawk Eye] — работают). 1 Evocation за уровень класса, некоторые требуют Alchemist Lv 5/10+.

**Material Cards** — расходный ресурс вместо MP. **5 цветов** (Red=животные/подвижность, Green=растения/спокойствие, Black=минералы/защита, White=духовное/интеллект, Gold=энергия) × **4 ранга** (B/A/S/SS, цена 20/200/2000/20000 г). Эффект Evocation масштабируется по рангу карты (обычно 4 строки эффекта B/A/S/SS в данных заклинания). Можно делать "Crude Cards" из лута (10 мин работы Alchemy Kit'ом, ранг = цена продажи лута: B 10-99г, A 100-999г, S 1000-9999г, SS 10000г+); чистая прибыль почти всегда, лут при этом уничтожается.

**Alchemy Kit** (аксессуар: правая/левая рука/пояс/other) или **Card Shooter** (Stance:1H) — обязательный фокус.

**Использование:**
- **Major Action** — можно применить на несколько целей одновременно (Target:1 Character + Range 1/2, кол-во карт = базовое×число целей; при разных рангах карт эффект = по низшему рангу среди них), требует Evocation check (авто-провал = карты теряются впустую, эффект не срабатывает).
- **Minor Action** — только 1 цель, SV всегда 0 (без проверки, авто-успех целью при сопротивлении), не чаще 1 раза за ход; нельзя одновременно Major+Minor Evocation в один ход.
- **Combat Preparation** — как Minor Action (максимум 1 применение).
- Ограничение: в раунд использования Evocation нельзя делать Full Move.

**Evocations (Evocation Data, pp.190–198):** **26 Evocations** (9 на 1-м уровне класса, 10 на 5-м, 7 на 10-м; прежняя оценка «~28» была прикидкой), значки ▶▶ (Minor Action) и △ (Combat Preparation) как у спеллов. **Построчный список — `14-evocations.md`** (в приложении: `src/data/evocations.ts`). Magus Arts pp.181–184 — та же таблица без изменений.

**Для листа персонажа:** инвентарь Material Cards (5 цветов × 4 ранга, счётчик по каждому), Alchemy Kit/Card Shooter (экипирован?), список известных Evocations.

## Прогрессия и ограничения

- Все классы дают доступ к снаряжению ранга B.
- Для снаряжения ранга A, S — нужна соответствующая SCA (Combat Feat).
- Fencer: эффективная STR для снаряжения = STR/2 (округление вверх).
- Marksman не вносит вклад в Evasion (специфика механики зон).
- Некоторые расы запрещают определённые классы (см. 01-races.md).
