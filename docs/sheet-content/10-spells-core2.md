# SW 2.5 — Заклинания Core Rulebook II (дополнения к существующим школам)

Source: Core Rulebook II (EN translation), pp. 128–159.
Этот файл содержит ТОЛЬКО заклинания, добавленные Core II к школам, существовавшим в Core I.
Для новых магических систем (Fairy Magic, Techniques, Spellsongs) см. 11-fairy-magic.md и 12-techniques-spellsongs.md.

---

## Структура чтения заклинаний Core II

Некоторые заклинания Core II имеют суффикс II в названии — они **заменяют** заклинания Core I с тем же именем (принцип Non-overlapping Spells of the Same Name).

**Resistance: Temporary** — заклинание работает 10 секунд (1 раунд) при успешном сопротивлении, даже с Metamagic/Time.
