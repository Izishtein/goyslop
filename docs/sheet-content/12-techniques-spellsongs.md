Source: Core Rulebook II (EN translation), pp. 182–197.

Три новые «магические системы» для классов Enhancer и Bard, добавленных в Core II.
На листе персонажа они входят в секцию **«Techniques, Spellsongs, Stunts, etc.»**

---

## Techniques (技法) — Enhancer класс

**Enhancer** (Minor class) использует Techniques — физические преобразования тела.

### Механика

- Все Techniques используются **Minor Action** (►)
- Если Technique можно использовать в **Combat Preparation** — помечается △
- **Длительность** указана в каждой Technique
- **Fire Breath** и физические атаки используют: Enhancer Level + INT modifier = SV

## Spellsongs (呪歌) — Bard класс

**Bard** (Minor class) исполняет Spellsongs — магические мелодии с длительным эффектом.

### Механика Spellsongs

Поля каждого Spellsong:
- **Singing**: Required (нужно пение) или Not required
- **Pet**: Тип фамильяра/питомца для пения (Bird, Frog, Insect)
- **Effect Condition**: Необходимое количество Rhythm для эффекта
- **Resistance**: Neg (нельзя сопротивляться) или Can't
- **Type**: Psychic или Psychic (Weak) в большинстве случаев
- **Base Rhythm**: Rhythm генерируемый при исполнении (♩ = черта, ♡ = сердце)
- **Flourish Value**: Порог SV для Extra Rhythm
- **Extra Rhythm**: Дополнительный Rhythm при превышении Flourish Value

**默 (Rhythm)** — ресурс Барда:
- Генерируется при исполнении Spellsong
- Используется для активации эффектов с Effect Condition и Finales
- ♩ = один тип ритма, ♡ = другой тип ритма

**Базовый Performance check:** Performance SV = Bard Level + INT modifier

**Количество Spellsongs/Finales:**
- Базовое = Bard Level
- [Additional Songs I] +1, [Additional Songs II] ещё +1 (итого +2)

## Finales (フィナーレ) — Bard класс

Finales — одноразовые мощные эффекты, расходующие накопленный Rhythm.

### Механика Finales

Поля каждого Finale:
- **Rhythm Cost**: Количество и тип Rhythm, расходуемого на Finale (если несколько — все нужны)
- **Resistance**: Optional или Half
- **Type**: тип урона/исцеления

**Power формула для Finales:** Power X + Bardic Power (где Bardic Power = Bard Class Level + INT modifier)

**[Intense Finale]** (Combat Feat): Finale Power +10.
**[Confident Performer]** (Combat Feat): Финал с Resistance: Half меняется на Can't (Critical Threshold → None).

## Сводная информация для листа персонажа

### Секция на листе: «Techniques, Spellsongs, Stunts, etc.»

**Для Enhancer:**
- Список освоенных Techniques (название, длительность, эффект)
- Нет расхода MP (используются Minor Action)

**Для Bard:**
- Список освоенных Spellsongs (название, Singing, Pet, Effect Condition)
- Список освоенных Finales (название, Rhythm Cost, Resistance, Type)
- Счётчик Rhythm (♩ и ♡ отдельно)
- Bardic Power = Bard Level + INT modifier
- Pet (тип: Bird / Frog / Insect — влияет на доступные Spellsongs)

### Ограничения

- **Grassrunner** не может использовать MP, но Techniques — ДА (они не требуют MP)
- **Spellsongs** — Bard не может делать Major Action пока поёт (кроме случаев с [Battle Hymn])
- **Lullaby** и другие заклинания «Singing: Required» требуют, чтобы Bard пел — без голоса не работают
