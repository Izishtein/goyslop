# Design & UX — Open Questions

## Общая концепция

- Близко к бумажному листу (TTRPG-эстетика) или современный clean UI?
- Тёмная / светлая / системная тема?
- Какая референс-эстетика: японские TRPG листы, Foundry VTT, D&D Beyond, кастомная?

## Структура страницы

- Один длинный скролл vs вкладки (Basic / Combat / Spells / Inventory)?
- Боковое меню для навигации по секциям?
- Компактный и расширенный вид?

## Inline editing

- Клик по полю — редактирование на месте?
- Или режимы "просмотр" / "редактирование"?

## Визуальный язык

- Таблица характеристик: горизонтально (как в книге) или карточки?
- Классы и уровни: список строк или "class badges"?
- HP/MP: прогресс-бары или просто числа (current / max)?
- Снаряжение: таблица или карточки предметов?

## Размер экрана

- Целевое устройство: десктоп мастера / планшет игрока / телефон на столе?
- Фиксированная ширина (имитация A4) или responsive layout?

## Иконки и арт

- Иконки для типов снаряжения, школ магии, рас?
- Аватар персонажа (загрузка изображения)?
- Лицензионно чистые иконки (Lucide, Phosphor, game-icons.net)?

## Доступность

- Важна ли WCAG-совместимость?
- Клавиатурная навигация по полям?

## Локализация UI

- Термины на каком языке: JP (как в оригинале) / RU / EN / переключатель?
