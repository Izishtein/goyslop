# Готовые персонажи для быстрого старта

Семь персонажей 1 уровня, по одному на иконный архетип, чтобы сесть играть без создания
персонажа с нуля (§ 5.2 `docs/roadmap.md`). Характеристики посчитаны через Point Buy
(бюджет ≤ 0 по формуле из `src/lib/formulas/point-buy.ts`), снаряжение — по таблицам
Core Rulebook I (B-ранг). Корректность каждого файла против реальной схемы и каталогов
приложения проверяется тестом `src/data/pregens.test.ts`.

| `Нибл_Тихолап.sw25.json` | Нибл Тихолап | Таббит | Sorcerer | Атакующий маг (Истинная Речь) |

## Как взять персонажа

**В приложении:** кнопка **«Быстрый старт»** в шапке (или ссылка прямо на пустой форме
создания персонажа) открывает галерею всех семи — карточка с расой/классом/HP/MP/историей
и кнопкой «Взять этого персонажа». Клик добавляет свежую копию в ростер (новый `id`, как у
«Дублировать») и делает её активной; один и тот же архетип можно взять больше одного раза —
для второго игрока, который тоже хочет Fighter'а. Эти файлы попадают в сам бандл приложения
(`src/features/quick-start/QuickStartView.tsx`, `import.meta.glob`), так что галерея
работает и на задеплоенном сайте, без доступа к репозиторию.

**Вручную, из файла:** кнопка «Импортировать JSON» в шапке ростера — загрузить
`roster.sw25.json` (все семеро разом) или любой отдельный `<Имя>.sw25.json`. Тот же
обработчик, что и для любого другого экспортированного персонажа
(`parseImportedCharacters` в `src/features/character-io/characterIo.ts`), но требует, чтобы
файлы были на диске — годится при работе с репозиторием локально, не на хостинге.

## Что не покрыто

Каждый персонаж — минимальный, но играбельный уровень 1: одна стартовая раса/класс/фон,
базовое оружие и броня B-ранга, один боевой фит (SCA), у заклинателей — заклинания 1 круга
своей школы из Core Rulebook I. Дальнейший рост (уровни, снаряжение выше B-ранга,
дополнительные заклинания и черты) — обычная работа игрока в приложении после того, как
персонаж взят за стол.
